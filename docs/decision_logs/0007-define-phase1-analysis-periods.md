# 0007：第Ⅰ期分析の処置と期間を分ける

- **状態**：採用
- **決定日**：2026-08-29

## 決定

第Ⅰ期の主分析では、2013年3月25日に開業した当初11停留所の近接地点を処置群とし、
2000～2015年の完全パネルを使う。

2000～2017年は補助分析とする。2016年には日立商業高校停留所が追加されたため、
この期間の結果を当初11停留所だけの純粋な導入効果とは呼ばない。

主分析の開始年について、2005～2015年と2009～2015年を感度分析とする。完全パネルは
各分析期間について元の地点年表から別々に作り、2025年まで観測が続くことを条件にしない。

## 理由

- 2016年の停留所追加と2018年以降の第Ⅱ期による処置内容の変化を、2013年当初の導入と
  区別するため。
- 長期完全パネルを先に選んでから短い期間へ切ると、分析終了後に廃止された地点まで
  除外されるため。
- 2005年の日立電鉄線廃止と2009年の基本構想公表を踏まえ、開始年への依存を確認するため。

## 影響

- 地価公示と都道府県地価調査は引き続き別々に分析する。
- 第Ⅱ期を含む稼働アクセス分析は、主分析ではなく補足的な探索とする。
- この決定は、距離閾値、共変量、推定手法、固定効果、推論方法の採用を意味しない。

## 再検討条件

地点同一性、処置地点数、同時期の別事業、事前適合または利用可能な推論方法を確認し、
主分析期間では研究質問に答えられないと判断した場合に再検討する。
