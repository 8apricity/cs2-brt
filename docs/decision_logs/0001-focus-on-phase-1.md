# 0001：当面の研究対象を第Ⅰ期とする

- **状態**：採用
- **決定日**：2026-08-13

## 決定

当面の研究対象を、2013年3月に運行を開始したひたちBRT第Ⅰ期とする。

## 理由

中間発表までに扱う範囲を明確にし、第Ⅰ期の導入前後へ調査を集中させるためである。第Ⅱ期以降は、第Ⅰ期の事後期間に影響を与える出来事として考慮する。

## 影響

- 研究質問、介入履歴、データ整理は第Ⅰ期を中心に記述する。
- 第Ⅱ期以降を、第Ⅰ期と同じ研究対象として無条件に統合しない。

## 再検討条件

中間発表後に、第Ⅱ期以降へ研究範囲を拡張するときに再検討する。
