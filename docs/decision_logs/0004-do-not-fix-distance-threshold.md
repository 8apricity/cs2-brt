# 0004：研究概要では距離閾値を固定しない

- **状態**：採用
- **決定日**：2026-08-13

## 決定

研究概要における「沿線地域」を、第Ⅰ期の停留所または運行経路の周辺地域とし、500m、800m、1.5kmなどの固定距離では定義しない。

## 理由

地価地点の分布、データの位置精度、想定する影響範囲を十分に確認する前に距離を固定すると、研究目的より先に処置群の定義を決めることになるためである。

## 影響

- [`research_overview.md`](../research_overview.md) では距離閾値を示さない。
- 停留所距離、経路距離、地区単位の曝露などを手法候補として排除しない。

## 再検討条件

分析上の処置群・対照群の定義を正式に決めるときに再検討する。
