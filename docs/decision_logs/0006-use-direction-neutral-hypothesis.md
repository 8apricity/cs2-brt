# 0006：主仮説の方向を限定しない

- **状態**：採用
- **決定日**：2026-08-13

## 決定

主仮説を「BRT導入により沿線地価が変化した」とし、上昇または下落の一方向へ限定しない。正の影響、負の影響、明確な影響がない可能性を並列に検討する。

## 理由

交通利便性の改善は地価を上昇させ得る一方、停留所や専用道直近の負の外部性、既存交通との代替、人口減少などにより、負の影響または明確な変化がない可能性もある。上昇を前提にすると、分析や文献選択が結論へ引きずられるためである。

## 影響

- 研究概要、分析、結果の解釈で、上昇効果を前提としない。
- 想定するメカニズムは仮説であり、確認済み事実と区別する。

## 再検討条件

強い理論的根拠に基づき、分析前に方向付き仮説へ変更する必要が生じたときに再検討する。
