# 0005：対照群候補を日立市内に限定しない

- **状態**：採用
- **決定日**：2026-08-13

## 決定

研究概要では、対照群の候補を日立市内だけに限定しない。必要に応じて周辺自治体や類似地域も候補にできるものとする。

## 理由

同一市内の地点は市全体の変化を共有しやすい一方、地点数や処置前の比較可能性が不足する可能性がある。現段階で市外候補を排除する根拠がないためである。

## 影響

- 日立市内外の候補を検討可能な状態に保つ。
- 市外を使うこと自体を決定したものではなく、具体的な対照群の採用には別の根拠を必要とする。

## 再検討条件

対照群の選定根拠と分析対象地域を正式に決めるときに再検討する。
