# データ台帳

この文書は、現在保有するデータと、研究上の用途が具体化している未取得データの来歴・構造・制約をデータセット単位で整理する。ファイルの存在や部分的な内容確認と、分析へ利用できることの検証は別であり、台帳への掲載は分析への採用を意味しない。

## 状態の読み方

- **公式提供期間・時点・範囲**：公式提供ページで確認できるデータの提供範囲。全範囲を確認できていない場合は、その旨を明記する。
- **ローカル収録期間**：リポジトリ内のフォルダ名・ファイル名から確認した期間。
- **内容確認**：実際にファイルを読み込んで確認した範囲。記載がない年度を確認済みとはみなさない。
- **取得方法**：既存データは、ユーザーの確認により、すべて公式Web画面からダウンロードしたものとする。

既存データの取得日は、ユーザーの確認とローカルのメタデータに基づき、日付単位で記録する。Web画面で指定した細かな条件は記録が残っていないため、実際の収録範囲はローカルファイルから確認する。

### 加工済み地価標準データ

地価公示と都道府県地価調査は、公式XMLを正本入力、同梱Shapefileを照合用として、
資料別の全年度標準データを`data/processed/`へ生成する。GeoPackage、CSV、年度別
メタデータ、品質レポートを生成し、成果物自体はGit管理しない。2026年8月26日の
全年度実行では、全87年度のShapefile照合が合格した。

列、CRS、年度別スキーマ、特殊値、出力ファイル、再生成方法の詳細は
[地価データ加工仕様](data_processing.md)を参照する。processedの作成は分析手法の採用や
年度横断の固定地点パネル完成を意味しない。

地点候補、地点年表、BRT停留所との距離、ベースライン共変量を分析時に組み立てる規則は
[地価分析データ構造](analysis_data_structure.md)を参照する。この分析層は標準データの
地点同一性を確認済みに変更するものではない。

### 加工済みBRT停留所標準データ

停留所履歴42件、2022年公式バス停留所XML、歴史停留所の手動座標確認を結合し、
`data/processed/`へGeoPackage、CSV、品質レポートを生成する。2026年8月27日の実行では、
42件の一意結合、現行25件、第Ⅰ期当初11件、検証済み2件、暫定9件、対象内の座標重複
0件を確認した。成果物自体はGit管理しない。

結合、列、座標系、確度、品質検査、再生成方法の詳細は
[BRT停留所データ加工仕様](brt_stop_processing.md)を参照する。このprocessedデータの
完成は、距離閾値、処置群、分析手法の採用を意味しない。
