## 結論

国土交通省「不動産情報ライブラリ」の取引価格情報を使うと、公示地価・都道府県地価調査より多数の観測を得られる。しかし、公開データから分かる所在地は原則として**町・大字まで**であり、取引物件の緯度経度や番地は公開されない。また、「ポイント（位置）情報取得API」が返す点は、公式仕様上、**対象不動産そのものではなく最寄り鉄道駅の位置**である。したがって、公開データだけから各取引を「BRT停留所から500 m／800 m以内」と正確に分類することはできない。

この候補を実施するなら、名称は「取引単位」としても、処置は**町・大字単位のBRT曝露**として定義する必要がある。具体的には、開業時の停留所バッファと国勢調査町丁・字等境界を重ね、各地区の曝露割合を開業前に固定し、土地のみ・住宅地の取引単価を使った反復横断面ヘドニックDIDを行う。推定対象は「停留所近傍の個々の土地」ではなく、**BRT曝露地区で実際に売買された住宅地の価格変化**である。

予備集計では、日立市の土地のみ取引は2008～2017年に年97～239件ある一方、暫定的な第Ⅰ期沿線3町（大みか町・久慈町・みなと町）の住宅地は年10～22件程度で、四半期では0～10件と薄い。さらに実質的な処置地区数は2～3地区にとどまる可能性がある。このため、**年次・町大字単位なら実行可能性は中程度だが、単独の主たる因果推論には弱い**。固定地点DIDやASCMとは異なるデータ生成過程を使う補助分析・市場取引による三角測量として位置づけるのが妥当である。

## 1. データの内容、期間、空間精度、取得方法

### 1.1 公式データの性格

国土交通省は、登記情報を基に取引当事者へアンケートを行い、個別物件が容易に特定されないよう加工した情報を四半期ごとに公表している。これは「統計調査」ではなく、回答・非回答を含む取引市場の全数標本でもない。価格は丸められ、最新値を含め後日変更される場合がある。分析結果ではこの標本選択と測定誤差を明記する必要がある（[不動産取引価格情報とは](https://www.reinfolib.mlit.go.jp/realEstatePrices/about/)）。

収録は2005年第3四半期から始まるが、当初は対象地域が限定され、段階的に全国へ拡大した。日立市の現在のダウンロード結果には2007年から観測がある。ただし地域間の比較可能性を優先し、主分析の開始は全国的な収集がほぼ整う2008年第2四半期以降とし、実データの地区別欠落を監査する。

### 1.2 主な変数

取引価格情報取得API `XIT001` とCSVには、概ね次が含まれる（[XIT001公式仕様](https://www.reinfolib.mlit.go.jp/help/apiManual/xit001/)）。

| 分類 | 主な項目 | この研究での用途・注意 |
|---|---|---|
| 取引分類 | 種類、地域、価格情報区分 | 土地のみ・住宅地を主標本に限定 |
| 地域 | 市区町村コード、市区町村名、地区名 | 地区名は町・大字相当。番地や物件座標ではない |
| 価格 | 取引価格総額、㎡単価、坪単価 | 土地のみでは㎡単価の対数を主アウトカムにする |
| 土地 | 面積、形状、間口 | ヘドニック調整、外れ値監査。ただし丸め・欠測あり |
| 接道・規制 | 前面道路の方位・種類・幅員、都市計画、建ぺい率、容積率 | 構成調整。処置後に変化し得る項目の扱いに注意 |
| 交通 | 最寄駅名、駅までの時間 | 鉄道アクセシビリティの調整。BRT停留所距離ではない |
| 建物 | 延床面積、建築年、構造、用途、改装等 | 土地建物一体取引の別分析にのみ使用 |
| 時間・事情 | 取引時期、今後の利用目的、取引の事情等 | 時間は四半期まで。特殊事情は除外・感度分析 |

取引時期は契約日を原則とし、不明な場合には登記原因日等が使われ、公開粒度は四半期である。最寄駅所要時間も正確な連続距離ではなく、長時間帯ではカテゴリ化され得る。価格・面積にも丸めや上限処理があるため、細かな価格差や極端値を額面通りに解釈しない（[項目の説明](https://www.reinfolib.mlit.go.jp/realEstatePrices/about/)）。

### 1.3 位置情報についての決定的制約

公開CSVと `XIT001` は「地区名」までで、物件の緯度経度を返さない。`XPT001` はGeoJSONの点を返すが、公式仕様は「対象となる不動産の**最寄り駅のポイント**を返却」と明記し、複数取引が同一点にまとめられることもある（[XPT001公式仕様](https://www.reinfolib.mlit.go.jp/help/apiManual/xpt001/)）。この点からBRT停留所までの距離を計算すると、「最寄り鉄道駅からBRT停留所までの距離」を誤って物件距離として扱うことになる。

したがって、公開データで可能なのは次の範囲である。

- 町・大字名を[e-Statの町丁・字等境界データ](https://www.e-stat.go.jp/help/view-on/map/boundary_data)へ対応させる。
- 地区ポリゴンと、開業時停留所の500 m、800 m、1 kmバッファとの交差面積を計算する。
- 同じ地区内の全取引へ、地区レベルの曝露値を付与する。

地区重心を疑似的な物件位置とすることはできるが、地区内の全取引が同一点になり、境界付近で大きな誤分類を生む。これは補助的な定義感度としてのみ使い、「個別取引距離」と呼ばない。番地や取引IDが公開されないため、一般的な住所ジオコーディングを追加しても正確な物件位置は復元できない。正確な距離分析には、非公開ミクロデータまたは完全住所・座標と公開取引を結ぶ正当な結合キーが別途必要である。

### 1.4 取得と利用条件

取得方法は、ウェブ画面からのCSVダウンロード、またはAPIキーを申請して `XIT001` を年・四半期・市区町村単位で取得する方法がある（[検索・ダウンロード操作](https://www.reinfolib.mlit.go.jp/realEstatePrices/manual/)、[API一覧](https://www.reinfolib.mlit.go.jp/help/apiManual)）。APIキーは環境変数で管理し、リポジトリへ保存しない。

利用時は出典を表示し、加工した場合は加工内容を明記する。APIを用いたサービスとして公開する場合には、国土交通省が指定する免責表示も必要である（[利用規約](https://www.reinfolib.mlit.go.jp/help/termsOfUse/)）。研究用成果物にも「国土交通省『不動産情報ライブラリ』を加工して作成」と、取得日、抽出条件、除外規則を残す。

## 2. 取引種類とアウトカムの設計

### 主分析標本

主分析は次に限定する。

- 種類：土地のみ
- 地域：住宅地
- アウトカム：公表された取引価格（㎡単価）の自然対数
- 地域：日立市内を基本とし、対照候補を広げる場合は隣接自治体を別仕様とする
- 時期：2008年第2四半期～2017年第4四半期。2018年の第Ⅱ期開始前で打ち切る

土地のみを選ぶ理由は、土地価格への効果を最も直接に観察できるためである。土地建物一体の総額を土地面積で割っても、建物価値が混ざるので「地価」にはならない。ヘドニック価格論では、観察価格は属性の束に対する市場評価であり、属性構成を明示的に扱う必要がある（Rosen, 1974, [原論文](https://www.journals.uchicago.edu/doi/pdf/10.1086/260169?download=true)）。

### 別標本・補助分析

- **土地と建物**：主分析と混ぜず別モデルにする。対数総額を使い、土地面積、延床面積、築年数とその二乗、構造、用途等を調整する。
- **中古マンション等**：市内件数が少ないため、事前監査で十分なセル数がある場合のみ別分析にする。
- **商業地・工業地**：BRTによる異質な効果が考えられるが、住宅地とプールせず探索的分析とする。
- **農地・林地**：沿線住宅市場という研究対象から外す。

特殊事情欄に競売・調停、関係者間取引、私道を含む取引、隣地取得等がある取引は、主仕様では除外し、含めた結果を感度分析として示す。欠測を一括で落とすと標本構成が変わるため、変数ごとの欠測率を処置群×年で報告し、必要なら「欠測」カテゴリを使う。

## 3. 推定対象とモデル

### 3.1 推定対象

地区を \(a\)、取引を \(j\)、時点を \(t\)、地区の第Ⅰ期曝露を \(D_a\) とする。イベント時点 \(k\) の対象は概念的に、

\[
ATT_k^{tr}=E[\log P_{jat}(1)-\log P_{jat}(0)\mid D_a=1,\ t=k,\ j\text{ がその時点で取引された}]
\]

である。これは「曝露地区で、その時点に売買された土地」の取引加重平均効果であり、沿線の全土地、同じ土地の経時変化、個別停留所800 m圏の効果ではない。BRTが売却確率や売りに出される土地の質を変える場合、価格効果と取引構成変化を分離できないことが重要である。

### 3.2 反復横断面ヘドニック・イベントスタディ

基本式は次とする。

\[
\log P_{jat}=\alpha_a+\lambda_t+
\sum_{k\neq -1}\beta_k\{D_a\times 1(EventTime_t=k)\}
+X_{jat}'\gamma+\varepsilon_{jat}.
\]

- \(\alpha_a\)：町・大字固定効果
- \(\lambda_t\)：年固定効果（四半期仕様では年月四半期固定効果）
- \(X\)：面積の対数、形状、間口、接道、用途地域・建ぺい率・容積率、鉄道駅アクセスなど
- \(\beta_k\)：基準年に対する曝露地区の価格差の変化

主仕様の属性は、土地面積・形状・接道など比較的物理的なものに絞る。「今後の利用目的」などBRTによって変わり得る項目は処置後変数になり得るため、主仕様には入れず拡張仕様でのみ用いる。係数は対数点であり、厳密な百分率変化は \(100\{\exp(\beta_k)-1\}\) で示す。

単一の共通開業日を扱う限り、段階導入DIDに特有の「既処置群を対照にする」問題は中心ではない。ただしデータは同一物件のパネルではなく反復横断面である。条件付き平行トレンド、共通サポート、曝露地区から対照地区への波及がないこと、同時期の地区固有ショックがないこと、測定方法が安定していることが因果解釈に必要になる。反復横断面の二重ロバストDIDはSant'Anna and Zhao (2020) の枠組みを補助仕様に使える（[原稿](https://arxiv.org/abs/1812.01723)）。多期間ATTにはCallaway and Sant'Anna (2021) の方法がある（[原稿](https://arxiv.org/abs/1803.09015)）。

### 3.3 集計版を必ず併記する

各地区・年の価格中央値、または開業前ヘドニックモデルから得た品質調整済み価格指数を作り、地区年パネルでも推定する。これは情報を減らす一方、取引数の多い地区が過度に重くなることと、数百件の取引を数百個の独立な処置実験と誤認することを避ける。個票版と集計版の結論が大きく異なる場合は、構成変化または重みの影響を疑う。

## 4. 処置、対照、タイミング

### 4.1 処置地区の固定

`data/manual/brt_stop_history.csv` に記録された2013年3月25日時点の11停留所だけを用いる。現行停留所一覧から遡って定義してはならない。2016年2月1日追加の「日立商業高校」だけで新たに曝露する地区は、第Ⅰ期当初処置から除外するか、2016年追加処置として別に扱う。

町・大字境界は国勢調査GISの固定年版を使い、価格結果を見る前に次の曝露指標を作る。

1. 地区面積のうち停留所800 mバッファに入る割合
2. 可能なら、地区全体ではなく開業前の建物用地・可住地に限定した割合
3. 地区内に第Ⅰ期停留所が存在するか
4. 地区重心が800 m以内か（定義感度のみ）

主たる二値定義は、たとえば「開業前可住地の50%以上が800 m圏」のように、地理監査後・価格推定前に固定する。25%、50%、任意交差、1 kmなどを感度分析にする。曝露割合を連続処置として使う仕様も示せるが、地区内取引位置が不明なため個別距離勾配とは解釈しない。

### 4.2 対照地区

日立市内の非曝露住宅地から、開業前の価格水準・傾向、鉄道駅距離、用途地域、海岸・津波曝露、取引件数、人口・住宅構成が近い地区を選ぶ。次は除外または別仕様とする。

- 停留所バッファと一部重なる曖昧な地区（ドーナツ除外）
- 2018年以降の第Ⅱ期で処置される地区。主期間は2017年で終えるが、期待効果の可能性を監査する
- 大規模再開発や道路整備など、同時ショックが明確な地区
- 津波被害の強さが沿線と著しく異なる内陸地区

隣接自治体を追加すると対照数は増えるが、市固有政策や市場圏の差も増える。市内仕様を主、隣接自治体仕様を外的対照の感度分析とする。

### 4.3 時間の定義

開業日は2013年3月25日だが、取引時期は四半期までしか分からない。2013年第1四半期には開業前約3か月と開業後7日が混在するため、四半期分析では移行期として除外する。2012年第4四半期を基準とし、2013年第2四半期を最初の明確な開業後期とする。ただし売買交渉は契約より前に始まり、計画・工事の予期効果もあり得る。

予備集計では四半期セルが薄いため、主結果は年次とする。年次では2013年を移行年として除外し、2012年を最後の開業前、2014年を最初の完全な開業後年とする。イベントスタディ期間は2008～2017年とし、第Ⅱ期が始まる2018年へ延ばさない。

## 5. 主な脅威と対処

### 5.1 取引構成と選択

反復横断面では毎期別の土地が売買される。BRT後に小区画、駅近、接道条件のよい土地が多く売れただけでも、平均価格は変わる。次を行う。

- 処置群×年ごとに面積、形状、接道、用途地域、駅時間等の分布と標準化差を示す
- 開業前の属性分布へ再重み付けした推定を行う
- 共通サポート外を除外し、その割合を報告する
- 地区年の取引件数、可能なら住宅・宅地ストック当たり取引率を別アウトカムにする
- Sant'Anna and Xuの構成安定性検定を用いる（[論文原稿](https://arxiv.org/abs/2304.13925)、[compdid](https://psantanna.com/comp_did/index.html)）

構成安定性が棄却されたとき、単純DIDを「同じ種類の土地の値上がり」と断定しない。再重み付け結果を中心にするか、「観測された取引の価格変化」と限定する。

### 5.2 外れ値、丸め、欠測

- ㎡単価、総額、面積の分位点と散布図を年・種類別に確認する
- 主仕様は対数化し、事前規則による1%・99%トリムを感度分析にする
- 中央値・分位点回帰または地区年中央値でも再推定する
- 公表値の丸め・面積上限処理の影響を明記する
- 欠測率を処置群×時期で比較し、完全ケースだけの結果と欠測カテゴリを使う結果を比較する

公表㎡単価を主にし、総額÷面積で再計算した単価は丸め誤差確認にのみ使う。

### 5.3 空間誤分類と波及

同じ町・大字の取引へ同一曝露を付けるため、地区が大きいほど非古典的な測定誤差が起きる。複数の地区曝露定義、曖昧地区除外、境界年の変更、停留所一つ／地区一つを外す分析を行う。BRT効果が800 mを越える、または対照地区にも波及する可能性があるため、直近の非曝露地区を除外するドーナツ仕様も示す。

`DistrictCode` は地区更新等により時系列の連続性が保証されないため、コードだけを信用せず、正規化した地区名、境界ポリゴン、変更履歴のクロスウォークを保存する。

### 5.4 空間相関と少数処置地区

処置は取引ごとではなく地区ごとに割り当てられる。したがって取引行を独立な処置反復として扱った通常の標準誤差は過小になる。時系列相関を無視したDID推論の問題はBertrand, Duflo and Mullainathan (2004) が示している（[NBER原稿](https://www.nber.org/papers/w8841)）。

地区クラスタ標準誤差を基本とするが、処置地区が2～3なら通常のクラスタ漸近論も信頼できない。少数処置群の推論についてはConley and Taber (2011) の考え方を参照し（[原論文](https://direct.mit.edu/rest/article/93/1/113/57888/Inference-with-Difference-in-Differences-with-a)）、適格な非曝露地区へ偽の処置を順番に割り当てる空間プラセボ分布を重視する。wild cluster bootstrapも処置クラスタが極端に少ないと万能ではない（MacKinnon and Webb, 2017, [原論文](https://onlinelibrary.wiley.com/doi/abs/10.1111/ectj.12107)）。

Conley型空間HACは座標が必要だが、本データには取引位置がない。地区重心で計算するConley標準誤差は粗い感度分析に限り、位置問題を解決したとは扱わない（Conley, 1999, [原論文](https://www.sciencedirect.com/science/article/pii/S0304407698000840)）。

### 5.5 2011年東日本大震災

日立市沿岸は津波・住宅被害と復旧政策の影響を受けた。市資料は久慈港周辺等の浸水区域を示し（[地区別防災マップ](https://www.city.hitachi.lg.jp/_res/projects/default_project/_page_/001/004/794/chikubetsu_bousai_map.pdf)）、市の計画資料も多数の住宅被害と2014年3月までの復興計画を記録する（[日立市総合計画資料](https://www.city.hitachi.lg.jp/_res/projects/default_project/_page_/001/003/275/1souron.pdf)）。第Ⅰ期沿線は大みか・久慈の沿岸側を含むため、震災ショックが処置群だけで強ければ平行トレンドを破る。

対処は次の通りである。

- 実績浸水区域・海岸距離が近い対照地区を優先する
- `津波曝露×年` を加えた仕様、浸水地区内／外の層別を示す
- 2011～2012年を除く仕様、2008～2010年だけの偽開業、2012年以降だけの短期比較を併記する
- 震災後の復旧や道路整備がBRT導入経路の一部なら、それを単なる交絡統制とするか媒介効果とみなすかを明示する

2011年をダミー一つで吸収するだけでは、沿岸と内陸で異なるショックに対処できない。

## 6. Rでの実装案

使用候補は `httr2`、`jsonlite`、`readr`、`dplyr`、`stringr`、`sf`、`fixest`、`did`、`DRDID`、`compdid` である。`fixest::feols()` は固定効果回帰、`i()` はイベント時点の交互作用、`vcov_conley()` は座標が妥当な場合の空間共分散を実装する（[feols](https://lrberge.github.io/fixest/reference/feols.html)、[i](https://lrberge.github.io/fixest/reference/i.html)、[vcov_conley](https://lrberge.github.io/fixest/reference/vcov_conley.html)）。

概略は次の通り。

```r
# 1. APIまたは公式CSVを読み、原本は変更しない
# APIキーは Sys.getenv("REINFOLIB_API_KEY") から取得する

land <- trades |>
  filter(type == "宅地(土地)", region == "住宅地") |>
  mutate(
    unit_price = as.numeric(unit_price),
    log_unit_price = log(unit_price),
    year = parse_year(period),
    event_year = year - 2013L
  ) |>
  filter(year >= 2008L, year <= 2017L, year != 2013L)

# 2. 地区名を境界ポリゴンへ結合し、開業時停留所から作った
#    district_exposure を地区単位で付ける。物件座標とは呼ばない。

m_event <- fixest::feols(
  log_unit_price ~
    i(year, treated_district, ref = 2012) +
    log(area_m2) + land_shape + frontage_m +
    road_type + road_width_m + nearest_station_time |
    district_id + year,
  data = land,
  vcov = ~district_id
)
```

このクラスタ標準誤差は処置地区が少ない問題を解決しないので、係数図とともに地区割当プラセボの順位・p値を示す。四半期モデルは2013年第1四半期を除外し、2012年第4四半期を基準にする。

`did::att_gt()` は `panel = FALSE` により反復横断面を扱い、共変量、ブートストラップ、同時信頼帯を指定できる（[公式リファレンス](https://bcallaway11.github.io/did/reference/att_gt.html)）。処置群行の `gname` を最初の処置期、対照群を0として構成する。二期間へ集約した検証には `DRDID::drdid()` を使える（[公式リファレンス](https://psantanna.com/DRDID/reference/drdid.html)）。ただし、どのパッケージでも処置地区数そのものは増えない。

再現性のため、次を派生ファイルへ保存する。

- API／CSV取得日、期間、市区町村、価格区分
- 原変数から分析変数へのデータ辞書
- 地区名正規化・境界クロスウォーク
- 第Ⅰ期停留所集合と曝露閾値
- 各除外段階の行数
- 使用パッケージとセッション情報

## 7. 診断、プラセボ、感度分析

最低限、次を一つの診断表・図セットとして出す。

1. 地区×年×種類の件数、欠測率、価格p1・中央値・p99
2. 処置・対照の未調整平均と品質調整済み価格指数の時系列
3. 開業前イベント係数と同時信頼帯。非有意は平行トレンドの証明ではない
4. 2013年より前の偽開業年を使ったプラセボ
5. 同数・類似属性の非曝露地区を偽沿線にする空間プラセボ
6. 処置地区を一つずつ除くleave-one-district-out
7. 800 m／1 km、25%／50%、任意交差、重心、曖昧地区除外の定義感度
8. 2011～2012年除外、津波曝露整合対照、沿岸層別
9. 特殊取引の除外／包含、1・99%トリム、中央値集計
10. 未調整、最小属性調整、拡張ヘドニック、再重み付けDIDの比較
11. 取引件数をアウトカムとする選択診断
12. 土地建物一体取引を別標本で分析し、土地のみと符号・時期を比較

開業前係数を見て都合のよい期間や曝露閾値を選ばない。主仕様を価格推定前に固定し、全仕様を一覧表で示す。

## 8. 推定前サンプル監査

### 8.1 実施手順

1. 日立市の全取引種類を取得し、原本ハッシュと取得日を記録する。
2. 2008年第2四半期～2017年第4四半期の土地のみ・住宅地を抽出する。
3. 2013年開業時の11停留所を固定し、町丁・字等境界との交差を計算する。
4. 地区名称の未結合、1対多結合、境界変更を人手で確認する。
5. 地区×年／四半期の件数と属性欠測を集計する。
6. 価格を見ずに主曝露閾値、曖昧地区、対照適格条件を凍結する。
7. 処置地区ごとに少なくとも複数の開業前・開業後年があり、ゼロ件年が偏らないか確認する。
8. 独立な処置地区数を明示し、係数数に対してセルが薄すぎる場合は年をまとめる。

件数の機械的な合格基準だけで因果識別が保証されるわけではない。特に重要なのは、取引件数ではなく**独立な処置地区がいくつあるか**、対照との開業前傾向と沿岸ショックが比較可能かである。

### 8.2 2026年8月12日時点の予備監査

不動産情報ライブラリのウェブCSVを使った予備集計では、日立市の「土地のみ」は2007～2025年に3,265件あった。2008～2017年の年別件数は次の通りである。これは取得時点の速報的監査であり、最終分析ではスクリプトにより再取得・再現する。

| 年 | 全地域の土地のみ件数 |
|---:|---:|
| 2008 | 192 |
| 2009 | 181 |
| 2010 | 175 |
| 2011 | 97 |
| 2012 | 229 |
| 2013 | 239 |
| 2014 | 206 |
| 2015 | 239 |
| 2016 | 178 |
| 2017 | 155 |

2011年の急減は震災と回答・取引選択の両方を疑うべきシグナルである。暫定的に第Ⅰ期沿線と考えられる大みか町・久慈町・みなと町を使うと、住宅地・土地のみは2008～2017年合計165件、年10～22件であった。大部分は久慈町100件、大みか町65件で、みなと町にはこの抽出条件で観測がなかった。四半期では0～10件で、2011～2015年だけでもゼロ件セルがある。

この監査から、次が分かる。

- 市全体の個票数は固定地点地価データより多い。
- しかし沿線の有効な独立処置地区は実質2地区程度になる恐れがある。
- 四半期イベントスタディは過剰に細かく、年次を主にすべきである。
- 最終的な沿線地区は町名の推測でなく、停留所バッファと境界のGIS交差で確定する必要がある。
- 市外対照を増やしても処置地区数は増えないため、精密な標準誤差だけで弱点を隠せない。

## 9. 実行可能性と研究内での位置づけ

| 観点 | 評価 | 理由 |
|---|---|---|
| データ入手 | 高 | 公式CSV／APIがあり、2008～2017年を取得可能 |
| 価格観測数 | 中～高 | 市全体では年100～200件前後 |
| 停留所距離の精度 | 低 | 公開位置は町・大字まで。ポイントAPIは最寄り鉄道駅 |
| 沿線の標本数 | 中～低 | 暫定沿線住宅地は年10～22件、四半期は薄い |
| 独立処置単位 | 低 | 実質2～3町大字の可能性 |
| 取引構成の安定 | 要検証 | 毎期異なる物件、アンケート回答標本 |
| 震災交絡 | 高リスク | 沿岸沿線と2011年被害・復興が重なる |
| 年次補助分析 | 実行可能 | 地区曝露として慎重に定義すれば可能 |
| 単独の主因果分析 | 推奨しない | 空間誤分類、少数処置地区、構成選択が重なる |

この方法の強みは、公示地価等の少数固定地点とは別に、実際の市場取引を多数観察できることである。弱みは、固定地点と違って同じ土地を追わず、しかも公開位置が粗いことである。よって研究内では次の位置づけが適切である。

> **位置づけ：補助分析（市場取引による三角測量）。** 町・大字単位の年次反復横断面ヘドニックDIDを行い、固定地点DID／ASCMの方向と時期が実取引にも現れるかを確認する。GIS監査後に処置地区が十分増え、開業前傾向・構成・津波曝露が良好である場合に限り、共同主分析への格上げを検討する。

「取引単位の800 m圏DID」は公開データでは実施不能であり、その名称で結果を提示してはならない。一方、「BRT曝露町大字における取引価格DID」なら、限界を明記した探索的・補強的分析として価値がある。

## 10. 中間発表までの具体的な実装順

1. `brt_stop_history.csv` から2013年3月25日の11停留所を確定する。
2. 開業時停留所座標と固定した町丁・字等境界を重ね、地区曝露表を作る。
3. 公式CSVで2008～2017年の日立市取引を取得し、土地のみ・住宅地を抽出する。
4. 地区名クロスウォーク、変数辞書、除外フローを作る。
5. 地区年件数、取引属性、震災・津波曝露を監査し、主仕様を凍結する。
6. 未調整価格系列、年次ヘドニック・イベントスタディ、地区年中央値版を推定する。
7. 構成安定性、取引件数、偽開業、偽沿線、leave-one-outを実行する。
8. 固定地点DID／ASCMと符号・効果発現時期を比較し、一致・不一致の両方を報告する。

中間発表では、まず「公開取引データは個別物件座標を持たない」というデータ制約を図で示し、その後に町大字曝露への設計変更、予備件数、推定前診断を提示する。効果推定値を急いで一つ出すより、推定対象と位置誤差を正確に説明する方が研究の信頼性を高める。
