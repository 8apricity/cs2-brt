# 地価分析データ構造

この文書は、加工済みの地価公示・都道府県地価調査から、地点別の分析に使う
インメモリデータを組み立てる規則を示す。公式XMLから生成する標準データの仕様は
[地価データ加工仕様](data_processing.md)を正本とする。この分析データは
`data/processed/`へ保存せず、分析時に再計算する。

## 地点ID

`prepare_land_price_analysis_data()`は、一つの資料種別の全観測を受け取る。地価公示と
都道府県地価調査を混在させた入力は拒否する。

地点候補は、指定距離以内にある観測同士を連結した空間クラスタとして暫定的に作る。
既定の許容距離は10mだが、分析時に変更できる。`point_id`は資料種別を含む
`land_price_publication_00001`のような文字列であり、同じ収録データと同じ許容距離なら
入力行順によらず同じ観測へ同じIDを割り当てる。収録データまたは許容距離を変えた場合、
IDが変わることは許容する。

このクラスタは公式に確認された年度横断地点IDではない。10m以内に別々の標準地・基準地が
ある場合など、同じ`point_id`・同じ年に複数観測を含み得る。観測は集約・選択せず保持し、
後段の完全パネル抽出で除外できるよう診断列を付ける。

## 基本データ

### `point_year_panel`

標準データの`observations`全列と観測時点のgeometryを保持し、次を追加する。

- `point_id`
- `point_year_observation_count`
- `duplicate_point_year`

一行を一意にする列は引き続き`observation_id`である。`year`、`unit_id`、対数価格、
処置列は追加しない。

### `point_registry`

一つの`point_id`につき一行を持ち、代表geometryと次の診断値を収録する。

- `observation_count`
- `first_source_year`
- `last_source_year`
- `observed_year_count`
- `duplicate_point_year_count`
- `maximum_displacement_m`

地積、利用現況、道路条件など、年次で変わり得る属性は地点台帳へ固定しない。

### `quality`

地点照合の許容距離、地点クラスタ数、同一地点年の重複数、クラスタ内最大変位を
一行で要約する。

補足的な縦長`attributes`層は、現時点ではこの分析データへ結合しない。共変量候補は、
まず標準観測表の中核属性から明示的に選ぶ。

## BRT距離と曝露

`calculate_point_stop_distances()`は`point_registry`とBRT停留所から、全地点×全停留所の
`point_id`、`stop_id`、`distance_m`を返す。距離閾値による行の除外は行わない。

`derive_brt_exposure()`は、対象停留所IDと距離閾値を明示的に受け取り、閾値内で最も早く
開業した停留所を選ぶ。同じ開業日の候補が複数ある場合は最短距離を優先する。返り値は
地点別の曝露有無、停留所ID、開業日、距離であり、年次処置列は作らない。年次処置は、
各資料の`reference_date`と開業日を後段で比較して定義する。

`derive_brt_treatment_panel()`は、地点年表、全地点×全停留所距離、停留所の開始・終了、
一時的な運行休止を受け取り、基準日時点の稼働アクセス、停留所数、最寄り距離、
確度監査、変更日別のアクセス増減をインメモリで付加する。この返り値も
`data/processed/`へ保存しない。列の定義、現在の探索設定、推定前検査は
[BRT処置列の探索実装メモ](exploration_treatment_design.md)を参照する。

## 分析標本と共変量

`filter_complete_point_panel()`は、指定された各年にちょうど一観測ある地点だけを返す。
指定年は連続していなくてもよい。欠年または同一年に複数観測を持つ地点は除外する。

`build_baseline_covariates()`は、指定した一つの年に実際に観測された値から、地点別の
ベースライン表を作る。指定年に観測がない地点は含めず、欠損値は保持し、自動補完、
標準化、カテゴリーのダミー化は行わない。同じ地点に指定年の観測が複数ある場合は
処理を失敗させる。

共変量列は明示的に指定する。地点・観測ID、資料年、基準日、geometry、list列は
共変量として拒否する。価格は機械的には禁止しないが、処置前価格を共変量として
使うかは分析設定として別途判断する。

## 探索時の利用

使用例は[`analysis/exploration.R`](../analysis/exploration.R)に置く。第Ⅰ期の期間は
[決定0007](decision_logs/0007-define-phase1-analysis-periods.md)に従い、主分析を
2000～2015年、補助分析を2000～2017年、開始年の感度分析を2005年・2009年として、
それぞれ別に完全パネルを作る。2010年をベースライン年の暫定例としているが、BRT構想
公表後である可能性があるため、共変量設定としては未採用である。共変量列の既定値は
空であり、具体的な共変量セットも未採用である。1,500mという値、2000～2025年の
稼働アクセスモデル、分析手法も探索例であり、採用を意味しない。
